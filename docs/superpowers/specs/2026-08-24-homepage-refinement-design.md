# CSI Global Health 首页贴近确认稿设计

## 目标

在不改变 Astro、TypeScript、普通 CSS 和静态输出技术路线的前提下，将三语首页贴近已确认的视觉方向：国际科研机构感、医疗科技企业感与克制的创业气质。首页继续以公司沿革与日本 / 美国双中心为叙事主轴；BNCT 与 AtherOx® 为两个并列核心业务。

## 范围

本轮仅改造首页及其共用呈现层：页头、Hero、沿革、核心业务、顾问、全球网络、研究与新闻入口、页脚，以及这八个模块所需的三语数据接口和响应式规则。

不包括：内容管理系统、联系表单后端、AtherOx® 的诊断或疗效宣称、未确认的临床资料、外部地图组件、React/Vue、动画框架、确认稿截图作为网页背景。

## 实现方式

首页从单一 `HomePage.astro` 拆分为职责明确的共享组件：`Header`、`Hero`、`HistoryTimeline`、`BusinessCenters`、`AdvisorGrid`、`GlobalNetwork`、`ResearchNews`、`Footer`。`HomePage.astro` 只负责按顺序组装这些组件；`src/data/site.ts` 保持三语内容的唯一来源。

所有语言路径继续复用同一组件树。语言切换必须映射同页路径，例如 `/ja/atherox/` 对应 `/en/atherox/` 与 `/zh/atherox/`，不得回跳首页。

## 视觉规则

- 白色主背景、深海军蓝为结构色、CSI 红色只用于重点与 CTA。
- Hero 右侧使用 SVG 世界网络：日本为红色主节点，美国为第二中心，欧洲与中国 / 亚洲为合作节点；仅使用低频、尊重 `prefers-reduced-motion` 的 CSS 动效。
- 沿革采用桌面端四段横向叙事和移动端纵向时间线，清晰表达“冈山大学 → CSI → 日本/美国双中心 → 全球医疗创新”。
- BNCT 与 AtherOx® 采用并列主卡片，分别以红、蓝为重点；科研视觉使用原创抽象 SVG/CSS 图形，不直接使用确认稿或 PDF 幻灯片图。
- 采用统一细边框、轻阴影、较高留白与紧凑但不拥挤的版面节奏。

## 资产策略

- 直接纳入冈山大学 `title.svg`，作为正式矢量标识。
- 直接提取公司介绍 PDF 第 5 页的四位顾问肖像，以较高分辨率替换现有原型裁切图。
- 暂时保留现有 CSI 标识 PNG；后续若获得官方横版 SVG，再无损替换。
- AtherOx PDF 的图表、临床研究图、检测图和影像图不用于首页视觉。它们仅可在将来的研究资料页面中，经出处和合规确认后使用。

## 响应式与可访问性

桌面（1440px）以确认稿的视觉密度为目标；1024–1280px 保持两栏业务卡；768–1024px 将导航变为菜单并重排卡片；375–430px 采用单栏、纵向沿革和完整可访问菜单。

所有图片提供准确替代文本；导航和菜单提供键盘操作与 ARIA 状态；颜色不单独承载含义；动画遵从减少动态效果偏好。

## 验证

每个实现批次运行 `npm run build`，检查 `/ja/`、`/en/`、`/zh/`，并在 1440px 与移动端检查 Hero、双业务卡、顾问、沿革、网络与页脚。AtherOx 页面文案继续保持“研究 / 技术信息”定位。
